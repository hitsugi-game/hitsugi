# M47C 戦闘予告信頼性・中盤難易度 baseline（2026-07-26）

## 判定

- 戦闘予告は、実行を予約しない全表示を可視・title・ariaとも「行動候補」へ統一した。固定seed 200件で士気崩壊中の固有手を確定扱いせず、逃走候補を観測した。
- 灯のUI境界を、実機構と同じ`40未満=敵影の速度/追跡強化`、`0=加えて戦闘敵の攻撃/HP強化`へ統一した。機構のない15%固有警告は廃止した。
- 中盤の敵数値は変更しない。実マップの深層帰還判断線で素手policy瀕死率70.5%、戦術policy完遂率100%を観測し、計測後の`X`を60%に固定したためである。

## 測定契約

- fixture: 人物3代目、月齢15、熟達Lv6、4人。初期店装備を三度継いだ形見（generation 3、+36%）を装備し、`recalcStats → combatantFromChar`の実変換経路を通す。
- 地域: tier3入口の星骸の谷。通常遭遇はproductionの`pickEnemies(region, 'battle', depth, rng)`を使う。
- 連戦: `maps.gen.ts`の宣言数へproductionの`activeShadeCount`を適用し、入口floor 0=5戦、帰還線floor 3=8戦、主前floor 4=2戦を導出する。HP/MPを持ち越し、戦闘ごとに灯6、戦間12歩×0.45を減らす。バフ・能力低下はproduction同様に次戦で組み直す。
- シード: 各行400。経路抽選と戦闘乱数を分離し、同条件・同seedの完全一致を固定する。
- policy: 素手=通常攻撃のみ。戦術=瀕死回復、攻防強化、単体技の順。いずれも自動撤退と道具は使わない。
- 瀕死: run中に一人でも生存HP30%未満。完遂、全滅、終了HP/MP、行動数、灯0で始まった戦数を別々に集計する。

## 語り部・旧elite・地域主・主代わり

- 語り部は入口/帰還線/灯枯れの戦術policyすべて完遂100%。帰還線は素手瀕死19.8%・戦術瀕死10.0%、灯枯れは0.8%・0%で、対応する宿命より難しくならない。
- 旧nodeのelite poolは現歩行遠征には出ないため中盤本表から分離した。単戦は素手/戦術とも勝率100%、被HP0.2%/0.7%であり、歩行難易度の根拠には使わない。
- tier3地域主11体は全て中盤PTで素手/戦術とも勝率100%。ただし素手瀕死は星骸の谷19%、他10主は0–3%で、主ごとの手応えは均一でない。星骸の大熊だけを中盤全体の代表にしない。
- 主代わりは明灯/灯枯れ×宿命/語り部の4条件を実戦闘で測り、全行勝率100%。倍率は共通`scaleEncounterEnemy`で語り部0.78、灯枯れ攻撃1.4/HP1.2、主代わり攻撃1.5/HP2.2を固定した。

## 調整判断

- 採用gate: 実在する帰還線floor 3・宿命の素手瀕死`X=60%以上`、戦術完遂`95%以上`、戦術の瀕死率とHP p10が素手より悪化しない。現行値は70.5%、100%、44.0%対70.5%、67%対14%で合格。戦術側MP枯渇99.3%は、勝敗でなく資源と帰還判断へ圧力が出ている観測値として残す。
- 敵HP/攻撃の一律変更は行わない。入口を死亡圧へ変えるより、灯43から8影を全討伐する深層では素手全滅5.5%、戦術全滅0%となる現行差を維持する。敵を避ける実プレイや道具使用を含まないため、全プレイヤーの死亡率とは解釈しない。
- tier3主10体の低圧力は、数値一律上昇でなく、後続の「予告可能な主固有手筋」で個別に扱う。これは今回のWork2→Work3範囲外であり、未実装を合格扱いしない。
