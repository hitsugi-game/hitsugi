| 魔性収集 | 第二相の魔性が図鑑へ登録されず、全収集へ届かない | 第二相開始時に一度だけ登録し、神の記録を保持 |
| 星神の契約実績 | 祭の縁だけで180柱を契約済みと数える | 「識る」と「契る」を分離。契約は図鑑の契約記録と既存の星契り家譜に基づく |
| 収集率 | 四捨五入で未収集があるのに100%と表示する | 未完了は切り捨て、全収集時だけ100% |

## 検証運用の修正

- lintの対象を実際のsource・tests・scripts・設定へ明示し、Dotの生成キャッシュをアプリのコード検査へ混ぜない。
- Vitestはtest対象を明示し、worker上限を2とした。M43の月送り検査は有限回数と進行assertを使う。201 campaign、星籤1,000 seed×50回、合格値は減らさず、重い2検査のtimeoutだけ実測に合わせた。
- Viteの事前解析入口をゲームの`index.html`に限定し、素材確認用HTMLを混ぜない。
- 全CSSが64KiB予算を166 bytes超えたため、後続CSSで完全に上書きされる指定と未使用変数を削除。予算は引き上げていない。
- visual closureの対象UI hashを改行正規化で更新。素材権利、人間確認、採用段階のstatusは昇格していない。
