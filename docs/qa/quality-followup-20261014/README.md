## 修正内容

- Q15: 行番号ではなく星神IDで焦点を管理する。Tabの入口を1つ設け、矢印・Home・Endは閲覧可能な行だけを移動する。資源不足は閲覧を妨げず、焦点を動かすだけでは契約相手を選択しない。全封印・親なし・0件では入口を作らず、絞込み解除で復帰する。
- Q16: `cleared === true` と結末選択0・1・2がそろう場合に達成とする。選択の記録がない旧データは達成と推定しない。同じ千年紀で再戦する場合は、すでに選んだ答えの達成を保持する。ゲーム状態や保存値は変更しない。
- Q17: 既存の結末本文に合わせて「八季ごとに」を「代替わりのたびに」へ変更した。当主の寿命や交代時点の数値は変更せず、夜が残る帰結も維持する。
- 追加対応: 上記の回帰テストと実画面確認を追加した。目標判定はReact画面から `homeObjectives.ts` に分離し、テスト用exportによる開発時のFast Refresh警告を解消した。関数本体が分離前と同一であることを別レビュアーが確認している。
